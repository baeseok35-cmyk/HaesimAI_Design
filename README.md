# 중해심 AI · 사용자 및 시스템관리 화면 시안

실제 소스 경로: `D:\vibecoding_git\HaesimAI_Design`

## 추가된 사용자 화면

**`index.html`**을 열면 AAAS 사용자 UI가 실행됩니다. 좌측 하단 **시스템 관리**를 누르면 `index.html?view=admin#dashboard`로 이동하며 관리 화면 상단 **사용자 화면 ↗**으로 돌아옵니다. 두 화면은 하나의 HTML에 통합되어 있습니다.

- 푸른 그라데이션 홈, 어두운 채팅 검색 결과, 접이식 메뉴
- 사고정보 목록/등록/수정, 요약·누락정보·원문 패널
- 첨부/드롭/진행률/오류/재시도, 질의 추천, 출처 패널, 응답 전·후 비교
- 프롬프트 관리와 사용 이력, 기간·상태별 대화 이력, 사용자 알림
- 법령 체계도·통계·상세/출처/개정 이력 패널
- 질의/응답 설정, 재결서 초안 생성/편집/미완료 저장/내보내기

엑셀 사용자 UI No. 1~30의 확인 위치와 시안 범위는 **`USER_UI_REQUIREMENTS.md`**에 정리했습니다. 하단 **상태별 UI 확인**에서 지연·오류 화면을 재현할 수 있습니다.

공통 진입점은 `index.html`과 `entry.js`입니다. 사용자 화면은 `user.css`·`user.js`, 관리 화면은 `styles.css`·`app.js`를 선택적으로 로드합니다. 아래 내용은 시스템관리 시안 안내입니다.

## 실행

`index.html`을 Chrome 또는 Edge에서 열면 바로 실행됩니다. 별도의 설치나 빌드는 필요하지 않습니다.

로컬 서버로 확인하려면 이 폴더에서 다음 명령을 실행하고 `http://localhost:8077`을 엽니다.

```powershell
python -m http.server 8077 --bind 127.0.0.1
```

## 디자인 방향

- 남색 사이드바 + 보라색 주요 액션 + 밝은 회색 작업 영역
- 대시보드 → 관리 목록 → 상세/수정의 일관된 화면 흐름
- 관리 영역은 접히는 좌측 메뉴, 세부 분류는 탭, 검색/상태 조건은 목록 상단 배치
- 등록·설정은 폼, 단일 항목의 상세·수정은 모달 사용
- 데스크톱 중심의 관리 화면이며 태블릿·모바일에서는 단일 열과 접이식 메뉴로 전환

## 검증

Chrome에서 대시보드와 19개 하위 메뉴의 렌더링, 검색/페이지 이동, 문서 상세, 메타정보 수정 및 저장, 학습 생성/완료/모델 저장, 모델 활성화, 알림 등록/수정/삭제, 설정의 새로고침 후 유지 여부를 확인했습니다. 390px 모바일 화면의 가로 넘침 및 메뉴 열기도 확인했으며 검증 중 JavaScript 실행 오류는 없었습니다.

## 시안 범위

백엔드, 인증, 실제 문서 수집/처리, GPU 학습, 모델 배포 및 파일 백업은 연결되어 있지 않습니다. 모든 기관·사건·지표·모델·파일 정보는 디자인 검토를 위한 예시입니다. 표의 건수는 포함된 예시 데이터 수이며 대시보드 통계와 차트는 별도의 화면 구성용 수치입니다.

입력 및 변경 사항은 브라우저의 `localStorage`에 저장합니다. 저장소가 차단된 환경에서는 현재 페이지에서만 유지됩니다. 기본 예시로 전체 초기화하려면 개발자 도구 콘솔에서 아래 명령을 실행한 후 새로고침합니다.

```javascript
localStorage.removeItem('haesim-design-v1');
location.reload();
```

Noto Sans KR 글꼴만 Google Fonts에서 불러옵니다. 인터넷 연결이 없어도 맑은 고딕 등 시스템 글꼴로 기능은 정상 실행됩니다. 아이콘은 내장 SVG이며 외부 JavaScript 라이브러리를 사용하지 않습니다.

퍼블리싱 후 실제 서비스로 구현할 때는 권한별 메뉴 노출, API 연동, 업로드/검증 정책, 작업 상태 폴링, 서버 페이징, 감사 로그를 별도로 연결해야 합니다.


## Vercel 배포

HTML 파일 개수는 404의 원인이 아닙니다. 배포 폴더에 index.html이 포함되어야 합니다.

- Root Directory: 저장소에서 이 폴더까지의 상대 경로. 이 폴더 자체가 저장소 최상위이면 비워 두고, 상위 저장소를 연결했다면 `HaesimAI_Design`으로 설정합니다.
- Framework Preset: `Other`
- Build Command: 비워 둡니다.
- Output Directory: `.`
- 설정 변경 후 재배포합니다.

`vercel.json`은 빌드 없이 현재 폴더를 배포하도록 설정합니다. Root Directory는 Vercel 프로젝트 설정에서 지정해야 합니다. 기존 `/user.html`, `/user` 주소는 `/index.html`로 리디렉션합니다.

기본 주소는 사용자 화면이며 관리 화면은 `/?view=admin#dashboard`입니다. `entry.js`가 통합 HTML의 해당 레이아웃을 선택하고 CSS·JavaScript를 불러옵니다. 화면 전환은 문서 이동 방식이며 기존 브라우저 저장 데이터는 유지됩니다.
